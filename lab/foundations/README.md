# 로그 분석 기초 실습

부록 C의 작은 셸·JSON 실습을 위한 지원 파일이다. 다른 사건의 로그나 인증 정보,
모델 응답은 사용하지 않으며 네트워크 연결도 하지 않는다. 기존 합성 증거 8종과
독립된 입력을 새 디렉터리에 만든다.

## 준비

Bash 3.2 이상, Python 3.9 이상, jq가 필요하다. macOS의 Bash 3.2.57에서
Python 3.9.6·3.14.5와 jq 1.7.1·1.8.1로 본문 명령과 출력을 확인했다.
grep·sed·wc는 운영체제의 명령을 사용한다.
다른 버전에서는 출력과 종료 상태를 비교하고, 차이가 있으면 버전을 함께 기록한다.

실습 묶음을 푼 폴더에서 Bash에 들어간 뒤
`python3 foundations/generate.py foundation-work`를 실행한다. 생성기는 이미 있는
디렉터리를 덮어쓰지 않는다. 생성이 끝나면 `cd foundation-work`로 이동하여
부록 C를 따라 한다. `raw/`는 입력, `out/`은 결과, `input-sha256.json`은 입력의
SHA-256 목록이다. 실제 사건 파일이 있는 폴더에서는 실행하지 않는다.

## 지원 프로그램

- `generate.py`: 입력 12개를 결정적으로 생성한다. 난수나 현재 시각은 사용하지 않는다.

- `check_inputs.py`: 생성 당시의 입력 해시를 비교한다.

- `validate_jsonl.py`: UTF-8과 한 줄 한 JSON 값의 형식을 검사한다. 이벤트 필드의
  스키마 검사나 입력이 비어 있지 않다는 보장은 별도로 해야 한다.

- `to_utc.py`: 명시적 오프셋이 있는 연습용 ISO 8601 시각을 UTC로 변환해 정렬한다.
  시간대가 없으면 2로 끝나며, 로컬 시간대를 추정하지 않는다.

- `test_foundations.py`: `python3 foundations/test_foundations.py`로 독립 시험을
  실행한다. 새 임시 디렉터리에만 자료를 만들며 종료 시 그 임시 자료를 정리한다.

## 입력 범위

주소는 문서용 예약 대역만 사용한다. `192x0x2x14`는 주소가 아니라 정규식의 점을
설명하기 위한 문자열이다. JSON의 자료형 차이, 빈 줄, 끝나지 않은 JSON,
마지막 LF 누락, CRLF, 시간대 누락은 모두 의도적으로 만든 연습 조건이다.
이 합성 결과를 운영 차단 목록이나 실제 사고의 판정에 사용하지 않는다.
