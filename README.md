# 『터미널에서 시작하는 보안 분석 — Claude Code 실무 핸드북』 실습 자료

저자 방주원 · [GitHub juwon1405](https://github.com/juwon1405)

첫 책 『보안 실무자를 위한 네트워크 공격 패킷 분석』에서는 정상적인 통신을 이해하고 패킷 속 이상을 살피는 방법을 다뤘습니다. 이번 책에서는 AI의 답과 로그 원문을 대조하며 그 태도를 이어 갑니다. 확인한 사실과 추정을 나누고, 다른 분석가가 검토할 수 있는 조사 기록을 남기는 연습을 합니다.

이 저장소는 로그 분석·조사 기록·증거 보호를 연습하기 위한 합성 자료 생성기와 보조 스크립트를 제공합니다. 책의 원고나 PDF를 공개하는 저장소가 아니며, 디지털 포렌식 전반을 다루는 교재를 대신하지 않습니다.

## 실습 파일 받기

[Releases](https://github.com/juwon1405/claude-code-security-handbook/releases)에서 해당 버전의 **handbook-lab-files.zip**을 내려받으세요. GitHub가 자동으로 제공하는 Source code (zip)는 저장소 전체를 묶은 파일이므로 책의 압축 해제 절차와 구조가 다릅니다.

v0.1.0은 출판 검토 중인 원고에 대응하는 사전 공개 실습 파일입니다. 정식 출간판의 제공 파일은 아닙니다. 사용할 버전과 알려진 제약은 각 릴리스 설명을 함께 읽어 주세요.

1. [실습 안내](lab/README.md)의 환경과 주의 사항을 먼저 읽습니다.
2. 내려받은 실습 ZIP을 실제 사건 자료와 분리된 새 실습 폴더에 풉니다.
3. 압축을 푼 폴더에서 SHA256SUMS.txt로 파일을 확인합니다.
4. 같은 폴더의 README.md에 따라 합성 자료를 생성하고 해당 장을 진행합니다.

체크섬은 파일이 제공된 내용과 같은지 확인하는 수단입니다. 프로그램의 안전성이나 분석 결론의 정확성을 증명하지는 않습니다. 저장소에서 소스를 직접 읽는 경우에도 lab/README.md를 기준으로 구성과 실행 절차를 확인하세요.

## 포함한 자료

- lab/gen_lab_data.py: 기본 로그 8종의 합성 자료 생성기
- lab/bin/ 및 설정·규칙 파일: 구조화 출력 검산, 권한 설정, 훅 실습
- lab/case2/: 여러 로그를 연결해 판단하는 종합 사례
- lab/recovery/: 모의 응답의 실패 분류와 재처리 실습
- lab/foundations/: 셸·JSON·시각 변환 기초 실습
- lab/platform/preflight.py: 파일과 도구의 준비 상태를 읽는 오프라인 진단

각 폴더의 역할과 정확한 실행 명령은 [실습 안내](lab/README.md)에 있습니다. case2/INSTRUCTOR.md는 풀이 자료입니다. 독립적으로 분석한 뒤 대조하고, 분석할 로그와 함께 모델 입력에 넣지 마세요.

## 실행 환경과 확인 범위

책의 기준 환경은 Apple Silicon macOS입니다. 이 환경에서 실습 명령·출력과 오프라인 단위시험을 확인했으며, 일부 모델 실습에는 부분 확인 또는 미실행 항목이 있습니다. 모든 프롬프트가 같은 버전에서 같은 결과를 낸다는 뜻은 아닙니다.

Windows 독자를 위한 WSL2·Ubuntu 준비 절차는 부록 D에 있습니다. 실제 Windows 환경에서 책의 전체 실습을 실행한 상태는 아닙니다. Windows 네이티브 환경이나 PowerShell에서 Bash 명령과 샌드박스 실습을 그대로 사용할 수 있다고 가정하지 마세요.

Python, jq, Bash 등 필요한 도구와 장별 추가 의존성은 실습 안내에서 구분합니다. 8장의 JSON 검산에는 가상환경과 jsonschema가 필요합니다. 준비 상태 진단의 종료 코드가 0이어도 실습 통과나 샌드박스 작동을 뜻하지 않습니다.

Claude Code를 사용하는 단계에는 별도의 이용 계정과 인증이 필요하며 요금·사용량 제한이 적용될 수 있습니다. 합성 자료 생성과 오프라인 검산을 모델 호출과 구분해서 진행하세요.

## 안전하게 사용하기

실습 자료는 합성 데이터입니다. 실제 사건의 로그·증거·고객 정보·인증 정보를 넣지 마세요. 생성기는 대상 폴더의 같은 이름 파일을 덮어쓸 수 있으므로, 실제 자료가 있는 폴더를 생성 대상으로 지정하지 마세요.

자료에 등장하는 IP 주소와 도메인은 실습용 표기입니다. 예약 대역과 예시 도메인을 포함하며, 외부 조회·접속이나 실제 차단 목록 등록 대상으로 사용하지 마세요. 생성되는 suspicious.ps1은 문자열과 코드를 읽는 정적 분석 대상이며 실행하지 않습니다.

lab/CLAUDE.md와 lab/.claude/는 책에서 사용하는 실습용 지침·설정입니다. 개인 설정이나 운영 환경용 보안 정책이 아닙니다. 별도의 실습 폴더에서 내용을 확인한 뒤 사용하고, 실제 업무 프로젝트에 그대로 복사하지 마세요. 훅 비교용 설정은 시험 쓰기를 허용합니다. 지침 파일과 단순 문자열 검사 훅만으로 모든 쓰기나 외부 전달을 막을 수는 없습니다.

모델에 입력한 내용과 도구가 읽은 내용은 서비스로 전달될 수 있습니다. 실제 업무 자료를 다룰 때에는 자료 소유권, 조직의 처리 규정과 서비스의 데이터 처리 조건을 먼저 확인해야 합니다. 이 실습은 실제 자료의 외부 전달을 허가하지 않습니다.

생성형 AI는 그럴듯하지만 사실과 다른 설명을 내놓을 수 있습니다. 원문 인용의 일치와 JSON 형식 검사를 통과해도 판단까지 맞다는 뜻은 아닙니다. 확인할 수 없는 결론은 보류하고 원문·별도 계산·실행 기록으로 대조하세요. 이 책과 실습 파일은 환각의 완전한 제거, 증거의 법적 효력이나 법정 제출 요건 충족을 보장하지 않습니다.
