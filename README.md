# 터미널에서 시작하는 보안 분석 — Claude Code 실무 핸드북

책에서 사용하는 실습 예제와 합성 로그 생성기를 제공합니다.

1. [실습 파일 내려받기](https://github.com/Juwon1405/claude-code-security-handbook/releases/download/v0.3.5/handbook-lab-files-v0.3.5.zip)를 눌러 `handbook-lab-files-v0.3.5.zip`을 받으세요.
2. [처음 설치하기](lab/README.md#처음-설치하기)에서 설치를 시작하세요. 같은 안내가 ZIP 맨 위의 `README.md`에도 있습니다. Windows에서는 먼저 책의 부록 D를 펼치세요. macOS에서는 압축을 이미 풀었는지에 따라 안내된 방법을 고르세요.

책이나 실습에서 오류를 발견하면 [정정 제보(Issues)](https://github.com/Juwon1405/claude-code-security-handbook/issues)에 장·절과 확인한 내용을 남겨 주세요. 예시가 필요하면 합성 자료를 사용해 주세요.

[실습 자료 이용 및 공유 안내](lab/README.md#사용과-공유)
